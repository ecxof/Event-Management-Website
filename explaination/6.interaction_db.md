To interact with the database, their are 3 steps:
1. choose the collection from the database
2. ready the data and the condition, such as $document = [...] , 查询条件 + $set
3. use the function such as insertone(), updateone()


## for inserting database

ready the variable for inserting the dataset
```php
$postDocument = [
    '_id' => $postObjectId,      // 主键
    'post_id' => $postId,
    'user_id' => $userId,        // 谁发的
    'title' => $title,
    'content' => $content,
    'created_at' => $now,        // 时间戳
    'status' => 'active',        // 状态
];
```

after that use the inserone() function to insert dataset
```php
$db->selectCollection('posts')->insertOne($postDocument);
```


## For Updating the database
1. update the data need to find out which data want to modify
2. put the updated data into the $set
```php
$posts->updateOne(
    buildPostQuery($postId),   // find out which post want to modify
    [
        '$set' => $updates,    // update the data
    ]
);
```

## for delete database
There have two ways:
1. soft delete
soft delete is mean to use updateone() to change the status to deleted, we still can check the data
```php
$db->selectCollection('posts')->updateOne(
    buildPostQuery($postId),
    [
        '$set' => [
            'status' => 'deleted',
            'updated_at' => new MongoDB\BSON\UTCDateTime(),
            'deleted_at' => new MongoDB\BSON\UTCDateTime(),
            'deleted_by' => $userId,
        ],
    ]
);

```

2. hard delete
the only method use hard deleteone() is delete postlike
```php
$db->selectCollection('postLikes')->deleteOne([
    'post_id' => $storedPostId,
    'user_id' => $userId,
]);
```
