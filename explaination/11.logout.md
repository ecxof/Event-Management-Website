logout is achieved by frontend and backend

# What logout means here
Login saves the user in 2 places:
- server side -> `$_SESSION` (PHP session data) + a session cookie in the browser
- client side -> `localStorage.currentUser` (used by the frontend to know who is logged in)

So logout must clear BOTH sides, or the user still looks "logged in".

# backend (api/auth/logout.php)
Its job: empty the session, delete the session cookie, and destroy the server session.

## Step 1: only allow POST
Logout changes state, so it should not be a normal GET link. If the method is
not POST, reject it.
```php
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    http_response_code(405);
    echo json_encode([
        'success' => false,
        'message' => 'Method not allowed',
    ]);
    exit;
}
```

## Step 2: empty the session data
Set the session array to empty, so `user_id`, `role`, etc. are gone.
```php
$_SESSION = [];
```

## Step 3: delete the browser session cookie
The session id is stored in a cookie. We overwrite that cookie with an empty
value and a time in the PAST (`time() - 42000`), which tells the browser to
delete it. We reuse the same cookie settings (path/domain/secure/httponly) so
we delete the exact same cookie login created (see 4.session.md).
```php
if (ini_get('session.use_cookies')) {
    $params = session_get_cookie_params();
    setcookie(
        session_name(),
        '',
        time() - 42000,          // expire in the past = delete now
        $params['path'],
        $params['domain'],
        $params['secure'],
        $params['httponly']
    );
}
```

## Step 4: destroy the server-side session
Removes the session data that PHP stores on the server.
```php
session_destroy();

echo json_encode([
    'success' => true,
    'message' => 'Logged out successfully',
]);
```

# frontend (app.js)
When the user clicks the logout confirm button:
```js
byId('logout-confirm')?.addEventListener('click', async (event) => {
    event.preventDefault();
    try {
        await apiRequest('/auth/logout.php', { method: 'POST', body: '{}' });
    } finally {
        localStorage.removeItem('currentUser');   // clear the client side
        window.location.href = 'Login.html';       // send user back to login
    }
});
```
Notes:
- `body: '{}'` -> sends an empty JSON body just so it is a POST request.
- `finally` runs even if the backend call fails. This is on purpose: we still
  want to remove `currentUser` and go to the login page no matter what.
- `localStorage.removeItem('currentUser')` clears the client side, and the
  redirect to `Login.html` finishes the logout.

# The full loop
```
you click "logout"
  -> frontend POSTs to /auth/logout.php
  -> backend: $_SESSION = [] -> delete session cookie -> session_destroy()
  -> frontend (finally): remove currentUser from localStorage -> go to Login.html
  -> both server side and client side are now clean
```
