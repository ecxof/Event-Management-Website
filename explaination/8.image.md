# The overall process of upload image 
1. frontend upload the image
2. this image will be send by 'post' to the php file
3. check that the file size and upload to cloudinary, cloudinary give back the secure url
4. this secure url will send back to the front end by response, and post again by post, and then the url will save into the mongodb

# frontend
1. upload the image through the function we created in app.js
```php
async function uploadImage(type, file) {
    const formData = new FormData();
    formData.append('image', file);

    const response = await fetch(`${API_BASE}/uploads/image.php?type=${encodeURIComponent(type)}`, {
        method: 'POST',
        credentials: 'include',
        body: formData,
    });

    const text = await response.text();
    let data = {};

    try {
        data = text ? JSON.parse(text) : {};
    } catch {
        data = {
            success: false,
            message: text || `Upload failed with status ${response.status}`,
        };
    }

    if (!response.ok || data.success === false) {
        throw new Error(data.message || `Upload failed with status ${response.status}`);
    }

    return data.image_url || '';
}
```

# uploading the image
1. First need to ensure the request method is post, user must be login 
```php
requireMethod('POST');
$userId = requireLogin();
```

2. choose which cloudinary folder to use, based on the type (post/event/avatar)
```php
function uploadFolder(string $type): string
{
    return match ($type) {
        'avatar' => 'event-management/avatars',
        'event' => 'event-management/events',
        'post' => 'event-management/posts',
        default => respond(422, [
            'success' => false,
            'message' => 'Upload type must be post, event, or avatar',
        ]),
    };
}


$folder = uploadFolder($type);
```

5. upload the file to cloudinary, and get back the url
```php
$config = require __DIR__ . '/../../connect_db/config.php';
$cloudinaryConfig = $config['cloudinary'] ?? [];

try {
    // Upload the local temporary file and let Cloudinary return a permanent HTTPS URL.
    $cloudinary = new Cloudinary([
        'cloud' => $cloudinaryConfig,
    ]);

    $result = $cloudinary->uploadApi()->upload($tmpName, [
        'folder' => $folder,
        'public_id' => $userId . '_' . bin2hex(random_bytes(8)),
        'resource_type' => 'image',
        'overwrite' => false,
    ]);
} catch (Throwable $error) {
    respond(500, [
        'success' => false,
        'message' => 'Cloudinary upload failed: ' . $error->getMessage(),
    ]);
}

$imageUrl = (string) ($result['secure_url'] ?? '');

```
