# Database
---
For the database, we used online database and cloudinary as our image transform

## connect_db/config.php

```php
<? php
return [
    'mongodb_uri' => 'mongodb+srv://<username>:<password>@<cluster>.mongodb.net/',
    'database' => 'event_management',

    'cloudinary' => [
        'cloud_name' => '<your_cloud_name>',
        'api_key' => '<your_api_key>',
        'api_secret' => '<your_api_secret>',
    ],
]; 
```

And then we apply the config in db.php file

## connect_db/db.php
```php
<?php

//To use the autoloading file to use mongodb
require __DIR__ . '/../vendor/autoload.php';

//create a variable $config and save the return variable into it
$config = require __DIR__ . '/config.php';

//turn the variable that save in $config into lowercase
$mongodbUri = strtolower($config['mongodb_uri']);

//check that either the string is contain unavailable username and password
if (str_contains($mongodbUri, 'username') || str_contains($mongodbUri, 'password')) {
    die('Please update mongodb_uri in config.php first.');
}

//try connecting to the mongodb, if failed then print out the error.
try {
    $client = new MongoDB\Client($config['mongodb_uri']);
    $db = $client->selectDatabase($config['database']);
} catch (Throwable $e) {
    die('MongoDB connection error: ' . htmlspecialchars($e->getMessage(), ENT_QUOTES, 'UTF-8'));
}
```
