# 1.0 When the user login/register, the session have already saved the user role

```php
//Login part
$_SESSION['role'] = (string) $user['role'];

//Register
$_SESSION['role'] = 'user';
```

## 2.0 Using helpers.php to identify the user role, by identifying the user role that store in session
```php

//this is to ensure that if the user is non admin, then cannot access the file (from event helper)
function requireAdmin(): void
{
    if (!isset($_SESSION['user_id'])) {
        respond(401, [
            'success' => false,
            'message' => 'Please log in first',
        ]);
    }

    if (($_SESSION['role'] ?? '') !== 'admin') {
        respond(403, [
            'success' => false,
            'message' => 'Admin access required',
        ]);
    }
}

//checking either is admin or not to do the different task (from post helper)
function isAdmin(): bool
{
    return ($_SESSION['role'] ?? '') === 'admin';
}

```
